# Shortlist Produk Awal NainPicks

Dokumen ini adalah daftar kandidat yang dipakai `AffiliateProductSeeder` untuk
mengganti data demo. Semua produk berada di kategori Shopee/TikTok Shop yang
sinyalnya kuat dari data publik (riset pasar Compas, laporan 11.11, dan
tracker produk pihak ketiga).

## Catatan penting

- **Harga adalah kisaran pasar**, bukan harga real-time. Harga di database
  memakai satu nilai estimasi dan bisa berubah kapan saja.
- **Komisi adalah estimasi** dari rentang umum program afiliasi per kategori.
  Angka final selalu mengikuti dashboard Shopee Affiliate / TikTok Shop Anda.
- **Tautan produk saat ini mengarah ke halaman pencarian marketplace**, bukan
  link affiliate. Setelah link tersedia, ganti lewat
  `/kelola/affiliate-products/{id}/edit` atau tab **Tujuan Link**.
- **Stok tidak dideteksi otomatis.** Status stok diubah manual di tab
  **Tujuan Link**.
- Angka penjualan/trending dari sumber publik hanya untuk prioritas kurasi,
  bukan klaim penjualan akun Anda.

## Alur mengganti tautan pencarian menjadi link affiliate

1. Buka `/kelola/affiliate-link-builder`, pilih sumber traffic (misalnya
   `ig_story`), lalu buat link ke halaman produk.
2. Salin link affiliate dari dashboard Shopee/TikTok Shop.
3. Buka produk di `/kelola/affiliate-products`, tempel di **Tautan affiliate**.
   Tujuan utama ikut diperbarui otomatis.
4. Jika ada link cadangan (toko lain), tambahkan di tab **Tujuan Link** dan
   atur status stok secara manual.
5. Cek link lewat tombol **Tes link** sebelum dipakai di postingan.

## Impor massal link & gambar (CSV)

Cara tercepat mengisi 46 produk: unduh template dari
`/kelola/affiliate-import` (tombol **Unduh template CSV**), isi kolomnya, lalu
unggah kembali di halaman yang sama.

```csv
slug,affiliate_url,image_url,price,original_price
wardah-cushion-series,https://s.shopee.co.id/abc123,https://down-id.img.susercontent.com/file/xxxx,129000,159000
jisulife-life-9-portable-fan,https://s.shopee.co.id/def456,,179000,229000
```

- Kolom wajib: `slug`, `affiliate_url`.
- Kolom opsional: `image_url`, `price`, `original_price`.
- `image_url` diunduh ke perpustakaan media bila opsi **Unduh gambar**
  dicentang.
- Pemisah koma atau titik koma sama-sama didukung.
- Produk yang link-nya masih berupa pencarian ditandai badge **Pencarian** di
  daftar produk, supaya mudah dicek mana yang belum diganti.

Lewat CLI:

```bash
php artisan affiliate:import-product-links path/ke/file.csv --download-images
```
